# Habit Tracker

A Habit Tracker built with plain HTML, CSS, and JavaScript.

## Tech Stack
- Plain HTML, CSS, JavaScript only
- Data stored in `localStorage`
- Run the app by opening `index.html` in Chrome (no build step, no server)

## Conventions
- Add a comment above each function explaining what it does
- Always confirm with me before adding a new feature or page that wasn't in the original request

## Do Not
- Add npm packages or a `node_modules` folder
- Add any new libraries without asking first
